# 🔐 Authentication Boilerplate

A production-ready authentication boilerplate built while learning modern backend development with **Node.js**, **Express**, **TypeScript**, **Prisma ORM**, **PostgreSQL**, and **Docker**.

This project is not just an authentication system but a reusable foundation for future full-stack applications.

---

## 🚀 Tech Stack

### Backend
- Node.js
- Express.js
- TypeScript

### Database
- Postgresql
- Prisma ORM

### Containerization
- Docker
- Docker Compose

### Planned Authentication
- JWT Authentication
- Refresh Tokens
- HTTP Only Cookies
- Google OAuth
- Email Verification
- Password Reset

### Validation & Security
- Zod
- bcrypt
- Helmet
- CORS
- Cookie Parser
- Rate Limiting
